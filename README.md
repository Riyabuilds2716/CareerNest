
# CareerNest - Job Portal

CareerNest is a full-stack Job Portal web application developed using Python, Flask and SQLite.

## 🌐 Live Website

https://careernest-b1hn.onrender.com/

## 💻 GitHub Repository

https://github.com/Riyabuilds2716/CareerNest

## 🛠️ Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript
- REST APIs
- Gunicorn
- Render

## ✨ Features

### Job Seeker

- Job seeker registration and login
- Search jobs by keyword and location
- View job details
- Apply for jobs
- View applications
- Profile management
- Help and Contact

### Admin Panel

- Secure admin login
- Dashboard statistics
- Manage jobs
- Add, edit and delete jobs
- Approve or reject job postings
- Flag or unflag job listings
- Manage applications
- Manage job seekers
- Edit and delete job seekers
- Manage employers
- Add, edit, view and delete employers
- Manage messages
- Activity Dashboard

## 🔌 APIs

CareerNest provides REST APIs for:

- Jobs
- Job search
- Job details
- Applications
- Job seekers
- Messages

Sensitive APIs are protected using admin authentication.

## 🗄️ Database

CareerNest uses SQLite for storing:

- Jobs
- Applications
- Job seekers
- Employers
- Messages
- Activities
